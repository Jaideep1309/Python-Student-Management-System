# Student Management System

A terminal-based Student Management System built using Python and SQLite.

## Features

- Add new student records
- View all student records
- Search students by ID
- Update student course details
- Delete student records
- Input validation to prevent invalid data
- SQLite database for storing student information

## Technologies Used

- Python
- SQLite
- SQL

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

   `python sqlite_test.py`
